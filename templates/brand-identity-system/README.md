# Vector Brand Identity & Logo Design System
### Mathematical Vector Generation & Comprehensive Brand Guidelines

An automated, precision-crafted brand identity suite that generates infinite-resolution vector SVGs, app store squircle icons, favicons, and complete brand style guides.

---

## Deliverables Generated
1. **Primary Vector Logo (`logo_primary_dark.svg`)**: Horizontal lockup with geometric tech mark and clean typography.
2. **App Store Squircle Icon (`app_icon_512.svg`)**: Standard 512x512 squircle icon formatted for Google Play & iOS App Store.
3. **Web Browser Favicon (`favicon.svg`)**: Crisp vector favicon.
4. **Monochrome Print Lockups (`logo_monochrome_dark.svg`, `logo_monochrome_light.svg`)**: High-contrast black/white single-color variants for merchandise and stationery.
5. **Brand Style Guidelines (`BRAND_STYLE_GUIDELINES.md`)**: Full color hex codes (`#6366F1`, `#06B6D4`), typography rules, clear space definitions, and dos/don'ts.

---

## Usage
Run the generator for any custom client or brand:
```bash
python generate_brand_assets.py
```
Outputs all assets directly to the `assets/` directory.
